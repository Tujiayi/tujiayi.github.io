# Website maintenance

- This is a local academic website based on al-folio v1.2. Follow the owner's workspace instructions when the workspace is available.
- Keep site changes in these pages, the academic layout and stylesheet, or the site configuration. Keep the upstream theme and dependency lock intact unless updating them deliberately.
- Only approved content may enter this repository. The generated academic data is read by Jekyll. Keep the raw profile, original CV source, personal contact information and credentials outside this repository.
- Use GitHub Actions to build the site and Overleaf to compile CVs. The CV page may link to an approved Overleaf PDF.
- Review the source and a build-only artifact before release. The owner authorizes Git commits, pushes and public deployment.
