# Academic Profile

An English academic website built with Jekyll and [al-folio v1.2](https://github.com/alshedivat/al-folio/releases/tag/v1.2).

## Site maintenance

- About, Publications, Research and CV pages live in the _pages directory.
- The site uses the approved export in _data/academic.json. The complete academic source and original CV files are maintained separately.
- The CV page enables its download link when an approved Overleaf PDF is configured.
- GitHub Pages uses the GitHub Actions publishing source. Run **Build and deploy site** manually. The default run builds and uploads an artifact. The publish input enables deployment from main.
- For updates, fetch the official v1.2 successor from upstream and compare it with the pinned baseline b95d6d61a1b0663529094b1b5f4fbe8aa41f8a04. Review the theme and dependency changes together.
